# Windows setup

## Goal

Connect the EP-133 K.O. II to the PC and prepare to record the real MIDI mapping.

## Hardware

- EP-133 K.O. II powered on;
- USB-C data cable;
- recent Chrome or Edge;
- a direct PC USB port when possible.

## Check

1. Connect the K.O. II.
2. Open the player in Chrome or Edge.
3. Check Windows Device Manager for the Teenage Engineering audio/MIDI device.
4. In the future MIDI version of the player, select the EP-133 port.

## Record before scoring

Hit every pad in group A slowly and record its label, received MIDI note, velocity, channel, and release behavior. Repeat for B, C, and D. The result will become `docs/MAPPING_MIDI_EP133.md`.

## If the device does not appear

- try another USB-C data cable;
- avoid unpowered USB hubs;
- restart the browser after connecting;
- check the K.O. II MIDI settings.
