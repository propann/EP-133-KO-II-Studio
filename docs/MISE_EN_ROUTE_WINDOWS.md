# Mise en route Windows

## But

Connecter le EP-133 K.O. II au PC et préparer le relevé du vrai mapping MIDI.

## Matériel

- EP-133 K.O. II allumé
- câble USB-C de données
- Chrome ou Edge récent
- un port USB direct du PC si possible

## Vérification

1. Brancher le K.O. II.
2. Ouvrir le player dans Chrome ou Edge.
3. Vérifier dans le gestionnaire de périphériques Windows que le périphérique audio/MIDI Teenage Engineering apparaît.
4. Dans la future version MIDI du player, sélectionner le port EP-133.

## Relevé à faire avant le scoring

Frapper lentement chaque pad du groupe A puis noter :

- label du pad ;
- note MIDI reçue ;
- vélocité ;
- canal ;
- comportement à la relâche.

Faire la même chose pour B, C et D. Le résultat deviendra `docs/MAPPING_MIDI_EP133.md`.

## Si la machine n’apparaît pas

- essayer un autre câble USB-C ;
- éviter les hubs USB non alimentés ;
- redémarrer le navigateur après branchement ;
- vérifier les réglages MIDI du K.O. II.
