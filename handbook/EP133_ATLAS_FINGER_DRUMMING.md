# EP-133 — Atlas de partitions Finger-Drumming

Version 1 — partitions de départ jouables sur le vrai K.O. II.

## Disposition physique

```text
Groupes : [ A ] [ B ] [ C ] [ D ]

        7   8   9
        4   5   6
        1   2   3
        0   +   -
```

Convention : `x` = frappe, `-` = silence. Chaque ligne contient 16 pas :
`1 e & a 2 e & a 3 e & a 4 e & a`.

## Kit universel conseillé

| Pad | Rôle | Doigt conseillé |
|---|---|---|
| A-7 | kick grave | pouce gauche |
| A-8 | kick court / ghost kick | index gauche |
| A-9 | snare | index droit |
| A-4 | clap | majeur droit |
| A-5 | closed hat | index gauche ou droit |
| A-6 | open hat | majeur droit |
| A-1 | percus | annulaire gauche |
| A-2 | tom / rim | majeur gauche |
| A-3 | crash | annulaire droit |
| A-0 | sub hit | pouce droit |
| A-+ | vocal chop / FX | index droit |
| A-- | reverse / transition | annulaire droit |

Les groupes B, C et D peuvent contenir les mêmes positions avec d'autres sons :
B = kit alternatif, C = percussions, D = samples mélodiques ou vocal chops.

## 1. Hip-hop / Boom-bap — 86 BPM

```text
A-7 KICK   x--- --x- x--- ---x
A-9 SNARE  ---- x--- ---- x---
A-5 HAT    x-x- x-x- x-x- x-xx
A-1 PERC   ---- --x- ---- x--x
```

Accentuer les kicks 1 et 3, laisser le dernier hat légèrement en retard.

## 2. Trap — 140 BPM, sensation 70 BPM

```text
A-7 KICK   x--- ---- --x- ---x
A-9 SNARE  ---- ---- x--- ----
A-5 HAT    xxxx xxxx xxxx xxxx
A-6 OPEN   ---- ---- ---- x---
A-1 ROLL   ---- --xx ---- ----
```

Jouer les hats à faible vélocité, puis accentuer les rolls. Variante : remplacer
le roll final par `x-x-` pour apprendre sans crisper la main.

## 3. House / Disco — 124 BPM

```text
A-7 KICK   x--- x--- x--- x---
A-9 CLAP   ---- x--- ---- x---
A-5 HAT    --x- --x- --x- --x-
A-6 OPEN   ---- --x- ---- --x-
A-1 PERC   -x-- ---- -x-- ----
```

Le kick doit rester régulier comme une horloge. Le groove vient des hats et des
percussions, pas d'une avalanche de coups.

## 4. Techno — 132 BPM

```text
A-7 KICK   x--- x--- x--- x---
A-9 RIM    ---- x--- ---- x---
A-5 HAT    --x- --x- --x- --x-
A-6 OPEN   ---- ---- ---- x---
A-1 PERC   ---x ---- ---x ----
```

Ajouter un clap sur le groupe B uniquement toutes les 4 mesures.

## 5. Funk / Boogie — 108 BPM

```text
A-7 KICK   x--x --x- x--- --x-
A-9 SNARE  ---- x--- ---- x--x
A-5 HAT    x-xx x-xx x-xx x-xx
A-1 PERC   --x- ---- --x- -x--
A-6 OPEN   ---- ---x ---- ---x
```

Jouer avec des vélocités contrastées : hats 55–85, snare 100–115, ghost notes
35–55. C'est ici que le doigt commence à danser au lieu de faire de la plomberie.

## 6. Reggae / Dancehall — 92 BPM

```text
A-7 KICK   x--- ---- --x- ----
A-9 SNARE  ---- x--- ---- x---
A-5 HAT    --x- --x- --x- --x-
A-1 PERC   ---x x--- ---x x---
A-0 BASS   ---- --x- ---- --x-
```

Accent sur les contretemps. Garder de l'espace : le silence fait partie du riddim.

## 7. Drum’n’Bass — 174 BPM

```text
A-7 KICK   x--- ---- --x- -x--
A-9 SNARE  ---- x--- ---- x---
A-5 HAT    x-xx x-xx x-xx x-xx
A-1 PERC   ---x --x- ---x -x--
A-6 OPEN   ---- ---x ---- ---x
```

Commencer à 87 BPM, puis doubler le tempo après réussite. La snare doit rester
le phare : si elle disparaît, le bateau est déjà dans le mur.

## 8. Breakbeat / UK Garage — 132 BPM

```text
A-7 KICK   x--- --x- ---- x--x
A-9 SNARE  ---- x--- ---- x---
A-5 HAT    x-x- x-xx x-x- x-xx
A-1 PERC   --x- ---- -x-- ---x
A-6 OPEN   ---- ---x ---- ----
```

Déplacer occasionnellement le kick du pas 7 au pas 8 pour créer le rebond.

## 9. Electro / Glitch — 118 BPM

```text
A-7 KICK   x--- ---x x--- ----
A-9 SNARE  ---- x--- ---- x--x
A-5 HAT    x-x- xx-x x-x- xxx-
A-1 GLITCH ---- -x-x ---- x-xx
A-+ VOICE  ---- ---- --x- ----
```

Le groupe C peut recevoir des one-shots glitch et le groupe D des textures. Ne
pas les jouer en continu : un glitch rare paraît plus cher qu'un glitch épuisé.

## 10. Latin / Afrobeat — 104 BPM

```text
A-7 KICK   x--- ---x x--- --x-
A-9 SNARE  ---- x--- ---- x---
A-5 HAT    x-x- x-x- x-x- x-x-
A-1 CONGA  --x- ---x --x- ---x
A-2 SHAKER -x-x -x-x -x-x -x-x
```

Faire tourner les congas entre le groupe C et le groupe D pour travailler les
alternances de mains.

## Exercice de progression

1. Boucle uniquement kick + snare, 2 mesures, 60 BPM.
2. Ajouter les hats sans dépasser 80 % de vélocité.
3. Ajouter une seule percussion.
4. Jouer 4 mesures propres, puis 4 mesures avec une variation.
5. Enregistrer une version lente, normale et rapide.

Seuil Pad Hero recommandé : 90 % de frappes correctes, zéro décalage supérieur à
un demi-pas, et combo de 32 frappes.

## Format de lecture rapide

```text
Compte : 1 e & a 2 e & a 3 e & a 4 e & a
Main G : kick / hat / kick / hat
Main D : snare / hat / snare / perc
```

Pour un prochain export Pad Hero, chaque partition doit être convertie en
événements JSON avec `bar`, `beat`, `step`, `group`, `pad` et `velocity`.
