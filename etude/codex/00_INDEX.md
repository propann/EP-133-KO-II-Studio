# Notes Codex — veille EP-133 / EP Series

> Dossier complémentaire créé le 13 août 2026. Ces notes sont séparées de la documentation produit et ne remplacent pas `etude/` ni `docs/`.

## Objet

Ce dossier rassemble la recherche externe destinée à orienter EP-133 KO II Studio : dépôts GitHub, formats, SysEx, outils concurrents, licences, risques et pistes de travail.

Il ne contient pas de décision d’intégration automatique. Une information trouvée en ligne reste une piste tant qu’elle n’est pas reproduite dans le navigateur puis validée sur un vrai EP-133.

## Niveau de confiance

- **A — observé** : code, fixture ou fichier du dépôt consulté.
- **B — corroboré** : information répétée dans plusieurs projets ou accompagnée d’un test documenté.
- **C — à confirmer** : hypothèse, fork, discussion ou information sans reproduction locale.
- **Interdit** : action destructive, écriture SysEx inconnue, firmware ou ressource propriétaire sans autorisation.

## Règle de séparation

Les notes Codex peuvent évoluer rapidement. Toute conclusion retenue pour le produit doit ensuite être reportée explicitement dans la documentation canonique, avec sa source et son statut de validation matérielle. Aucun fichier de ce dossier ne doit être utilisé comme preuve qu’une fonction est validée sur machine.
